# VS Code Extension

## Installation

```
ext install orplex-tech.orplex-tech
```

## Features

- **Chat Panel** — Full chat interface in the sidebar
- **Code Actions** — Fix, explain, refactor selected code
- **Streaming** — Watch responses in real-time
- **Multi-Model** — Switch between models

## Usage

1. Open the Orplex panel (activity bar robot icon)
2. Type a message or select code and right-click
3. Choose "Orplex: Fix/Explain/Refactor Selected Code"

## Configuration

Settings are in VS Code Settings (`Ctrl+,`):
- `orplex.apiUrl` — Server URL
- `orplex.apiKey` — API key (optional)
- `orplex.model` — Model to use
- `orplex.mode` — Agent mode
