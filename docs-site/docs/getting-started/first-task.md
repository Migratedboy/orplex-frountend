# Your First Task

1. **Open Orplex** — Navigate to `http://localhost:5000`
2. **Start a chat** — Type a message in the chat input
3. **Ask it to code** — Try: "Create a simple Express server with a /health endpoint"
4. **Watch it work** — Orplex will stream its response, create files, and run commands
5. **Review changes** — Check the Changes tab to see what files were modified
6. **Approve or reject** — Accept or reject individual hunks in the diff view

## Example Prompts

| Mode | Prompt |
|------|--------|
| **Code** | "Build a REST API with user authentication" |
| **Plan** | "Analyze this codebase and suggest improvements" |
| **Ask** | "What does this function do?" |

## Tips

- Use **Code mode** for building and fixing things
- Use **Plan mode** for analysis and architecture discussions
- Use **Ask mode** for quick questions
- Select code and use right-click → "Orplex" for context-aware actions
