# Changelog

All notable changes to the Orplex Tech VS Code extension will be documented in this file.

## [0.1.0] - 2026-09-02

### Added
- **Chat Panel** — Full chat interface in the sidebar with streaming responses
- **Fix Code** — Select code → right-click → "Orplex: Fix Selected Code"
- **Explain Code** — Select code → right-click → "Orplex: Explain Selected Code"
- **Refactor Code** — Select code → right-click → "Orplex: Refactor Selected Code"
- **Inline Chat** — Select code → `Ctrl+I` / `Cmd+I` to ask for inline changes
- **Switch Model** — Quick-pick to switch between OpenRouter, NVIDIA, OpenAI, Anthropic models
- **CodeLens** — "Ask Orplex", "Fix", "Refactor" links above functions and classes
- **Diagnostics** — Push agent-detected issues to the Problems panel
- **Clear Problems** — "Orplex: Clear Problems" command to reset diagnostics
- **Status Bar** — Rocket icon in the status bar for quick access
- **Keyboard Shortcuts** — `Ctrl+Shift+O` / `Cmd+Shift+O` to open chat
- **Multi-Provider Config** — Settings for API URL, API key, model, and mode
- **Streaming** — Real-time token-by-token response streaming
