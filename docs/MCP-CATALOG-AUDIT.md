- The probe is intentionally shallow: it proves the endpoint speaks MCP (or demands auth) and that packages exist — it does not enumerate tools. The Connectors panel's test-connection (`listTools`) is the deep check.

- Living spec: `docs/MCP-OAUTH.md` §8.
